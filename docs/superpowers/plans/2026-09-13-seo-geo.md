# Dinametra Dashboard SEO/GEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add static-first SEO and Generative Engine Optimization to the single-route Angular dashboard without changing its visual design or data behavior.

**Architecture:** Keep crawl-critical metadata in `src/index.html` and public discovery files so crawlers can understand the application without executing Angular. Retain the existing SPA architecture and semantic page content; add only focused regression coverage and public crawl/GEO assets.

**Tech Stack:** Angular 21, TypeScript 5.9, Vitest via Angular CLI, Netlify static hosting.

**Spec:** `docs/superpowers/specs/2026-09-13-seo-geo-design.md`

## Global Constraints

- Canonical URL is exactly `https://dinametra-dashboard.netlify.app/`.
- Product identity is `Dinametra Crypto Market Dashboard` and must be described as a technical dashboard/project, not as an official Dinametra commercial product.
- Do not change the current visual layout, CSS, charts, filters, API integration, or data-loading behavior.
- GEO means Generative Engine Optimization, not geographic targeting.
- Keep crawl-critical information available in the initial HTML/static files; do not require SSR.
- Do not add fabricated ratings, reviews, ownership claims, prices, or social profiles.
- Commits must include `[skip netlify]` so this work does not consume Netlify deployment credit.
- Required verification commands are `npm test -- --watch=false` and `npm run build`; if execution is unavailable, report that limitation explicitly.
